
# 🌸 Iris Flower Classification Project

## 📌 Objective
This project demonstrates machine learning classification using the famous **Iris dataset**.  
The goal is to predict the species of an iris flower (Setosa, Versicolor, Virginica) based on its sepal and petal measurements.

---

## 📂 Dataset
- Source: [Iris dataset](https://archive.ics.uci.edu/ml/datasets/iris)  
- Features:
  - Sepal length
  - Sepal width
  - Petal length
  - Petal width  
- Target: Species (Setosa, Versicolor, Virginica)

---

## ⚙️ Methodology
1. **Data Loading & Exploration**
   - Summary statistics
   - Species distribution
   - Visualizations (pairplot, heatmap)

2. **Preprocessing**
   - Feature scaling using `StandardScaler`

3. **Model Training**
   - Algorithm: K‑Nearest Neighbors (KNN)
   - Train/test split

4. **Evaluation**
   - Accuracy score (~95–98%)
   - Classification report
   - Confusion matrix

5. **Prediction**
   - Model predicts species for new samples

---

## 📊 Results
- Accuracy: ~95–98%  
- Example prediction:  
    Input: [5.1, 3.5, 1.4, 0.2]
    Output: Iris-setosa
