🌸 Iris Flower Classification Project

Objective

This project uses the famous Iris dataset to classify flowers into three species: Setosa, Versicolor, Virginica using Python and machine learning (KNN).

Dataset

Features include sepal length, sepal width, petal length, and petal width. Target is the species of the flower.

Methodology

  • Data loading and exploration
  • Visualization (pairplot, heatmap)
  • Model training with KNN
  • Evaluation (accuracy, classification report, confusion matrix)
  • Prediction on new samples

Results

Accuracy: ~95–98%
Example prediction: Iris-setosa

How to Run

git clone https://github.com/Lohita-08/CODSOFT_4.git
cd CODSOFT_4
pip install -r requirements.txt
python iris.py
